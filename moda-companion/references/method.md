# 方法核心

## 判断顺序

世界与国家方向 -> 产业趋势 -> 行业供需 -> 产业链位置 -> 公司质地 -> 利润兑现 -> 股价位置 -> 仓位与证伪。

不要从股票出发再拼理由。先确定长期变化，再判断谁真正受益。

## 研究偏好

- 优先研究长期需求增长、供给受限、资源稀缺、扩产困难和产业链关键环节。
- 喜欢低位、冷落和预期差，但低位必须配合生存能力与改善路径。
- 买入逻辑要能用一句话说清楚；说不清就继续研究，不上强结论。
- 基本面决定能否买，长期空间帮助持有，逻辑、估值与趋势变化辅助卖出。
- 仓位表达确定性：核心、进攻、学习和观察不能混为一谈。
- 普通投资者用分散和时间控制风险，不使用无法承受的杠杆。

## 必问问题

1. 行业未来几年为什么增长？
2. 产业链最稀缺、最难扩产的环节是什么？
3. 公司是真受益还是蹭概念？
4. 收入、利润和现金流如何兑现？
5. 当前价格是否已反映大部分预期？
6. 公司是否具备持续经营和极端风险安全垫？
7. 什么事实会证明判断错误？
