# moda v4 产品要求

## 目标

输入 A 股名称或六位代码，生成一份来源可追溯、缺失不猜测的六层诊断报告。

## 必须满足

1. F1-F4 为 80 分，F5 低位与困境反转为 10 分，F6 修正项为 10 分，理论最高 100 分。
2. `根` 评级能够真实达到。
3. 四项修正必须作为独立 F6 且只计算一次，3 类 Hard Cap 必须在代码中执行。
4. Skill 模板、评分报告和 README 的栏目顺序一致。
5. 财务、主营、股东、公告、供需、人气、社交热榜、拥挤度、宏观政策均保留来源和状态。
6. 数据缺失标记 `需人工确认` 并增加未知可得分上限，不作为负面事实；保留原始分字段兼容旧报告。
7. 机构方法实际按 18 项展示；只有量化选股筛选和投资逻辑追踪参与机构方向 2 分判断，技术结构独立使用 easy-tdx 的 4 分结果。
8. 可选搜索结果按 `网络命中（未核验）/已搜索未命中/搜索失败，需人工确认` 分层；未核验线索不覆盖结构化事实，也不单独触发负面 Hard Cap。

## 输出

报告先显示总分进度条、评级和技术信号，再把六段框架式最终判断放入开头的一句话结论区域。下一段显示 easy-tdx 日 K 技术分析，包括当前价、支撑位、压力位、综合判断、日线简化缠论结构和 8 项标准指标，再显示六层进度条。其后显示六层评分、舆情风险、Hard Cap、机构方法、睡得着检查、纠错触发器和覆盖缺口；结尾不重复最终结论。

## 范围外

- 自动交易、账户连接和收益承诺。
- 保存浏览器 Cookie、登录状态或任何凭据。
- 用人物角色口吻代替证据分析。
- 在数据不足时运行伪精确 DCF、LBO 或组合再平衡。
