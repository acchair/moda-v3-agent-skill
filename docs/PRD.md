# moda v4 产品要求

## 目标

输入 A 股名称或六位代码，生成一份与旧版最终框架一致、来源可追溯、缺失不猜测的五层诊断报告。

## 必须满足

1. 基础分由 24 个结构化子项组成，理论最高 100 分。
2. `根` 评级能够真实达到。
3. ±8 修正项和 4 类 Hard Cap 必须在代码中执行。
4. Skill 模板、评分报告和 README 的栏目顺序一致。
5. 财务、主营、股东、公告、供需、人气、社交热榜、拥挤度、宏观政策均保留来源和状态。
6. 数据缺失得 0 分，标记 `需人工确认`。
7. 机构方法实际按 18 项展示；只有两项技术复核可在双重冲突时降低 Alpha 1 分。
8. 可选搜索必须核验正文并满足双域名、双证据条件，不得使用摘要直接评分。

## 输出

报告先显示总分、评级和技术信号，再显示五层评分、修正、舆情风险、Hard Cap、机构方法、睡得着检查、纠错触发器、覆盖缺口和六段框架式结论。

## 范围外

- 自动交易、账户连接和收益承诺。
- 保存浏览器 Cookie、登录状态或任何凭据。
- 用人物角色口吻代替证据分析。
- 在数据不足时运行伪精确 DCF、LBO 或组合再平衡。
