# moda v3 产品需求文档

## 1. 产品定位

moda v3 是本地运行的 A 股研究工具。用户输入 6 位股票代码或名称后，系统采集公开行情、财务、技术、公告和产业链证据，按 F1-F5 五层框架生成可追溯报告。

网页工作台用于组织研究池、运行分析和查看市场信号，不提供自动交易，也不把候选或压力分数解释为投资建议。

## 2. 核心能力

1. 当前统一流水线运行 5 个模块：基础行情、深度财报、技术分析、公告互动、五层评分。
2. 报告写入 `knowledge/research/`，每项结论保留来源和缺失状态。
3. 网页工作台提供关联图谱、特征矩阵、股票列表、主动发现和市场压力五个视图。
4. 研究池状态保存在本地 SQLite，支持观察、核心跟踪和忽略。
5. 行业升温候选只通过精确行业关系生成，不自动加入研究池。
6. A 股市场压力按融资热度、指数弱势、行业集中度和市场广度计算。

## 3. 工作台流程

1. 搜索股票并打开右侧详情。
2. 查看实时行情、产业关系和已有 F1-F5 报告。
3. 将股票加入观察或核心跟踪，或直接运行分析。
4. 在底部终端查看流水线日志和模块结果。
5. 从主动发现查看行业升温候选，人工决定是否加入研究池。
6. 从市场压力查看指标、来源、有效权重和数据日期。

## 4. 数据与状态要求

- 行情单次最多查询 50 只，缓存 60 秒，单股失败不影响其他股票。
- 候选需要连续 10 个交易日的行业成交额占比数据。
- 压力总分至少需要 70% 指标权重；数据不足时总分为空。
- 所有接口返回来源、日期和 `live/cache/partial/unavailable` 等状态。
- 股票池操作必须校验股票存在，备注最多 500 字。

## 5. 范围外

- 自动交易、下单和账户操作。
- 美股股票池、跨市场映射、新闻抓取和 arXiv 论文发现。
- 模糊行业名称推断和自动把候选加入核心池。
- 对评分、压力或候选准确率作收益承诺。
