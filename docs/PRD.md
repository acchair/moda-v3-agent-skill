# moda v3 产品需求文档

## 1. 产品定位

moda v3 是本地运行的 A 股研究 Skill。用户提供 6 位股票代码或股票名称后，Agent 采集公开行情、财务、技术和公告证据，按 F1-F5 五层框架生成可追溯报告。

本项目只提供命令行分析与报告导出，不包含网页版、自动交易或账户操作。

## 2. 核心能力

1. `tools/run_pipeline.py` 是统一运行入口。
2. 流水线共享一次日 K 数据，并行生成基本面、技术和公告报告，最后生成五层评分报告。
3. 报告写入 `knowledge/research/`，每项结论保留实际来源和缺失状态。
4. 评分采用 F1-F5 五因子、保守硬约束和固定评级：根、矛、学习仓、不碰。
5. 仅在用户需要文件时，通过 `tools/export_skill_output.py` 导出最终答复。

## 3. 使用流程

1. 将股票名称解析为 6 位 A 股代码；存在歧义时明确提示。
2. 运行 `python tools/run_pipeline.py --stock {code} --name {name}`。
3. 读取 `knowledge/research/pipeline/{code}.json`，只使用本次运行成功的模块报告。
4. 汇总 F1-F5 分数，检查 ST/退市、控股股东减持和 F1/F3 硬限制。
5. 输出总分、评级、来源、缺失项、风险与证伪条件。

## 4. 数据与状态要求

- 数据源失败时标记 `需人工确认`，不得把旧报告当作本次结果。
- 缺失数据不得自动转为正面结论。
- 每项关键结论必须标注实际来源。
- 股票代码必须为 6 位数字。
- 密码、Token、Cookie 和代理凭据只能通过环境变量提供，禁止写入报告和仓库。

## 5. 范围外

- 网页版、研究池、市场看板和产业链数据库。
- 自动交易、下单和账户操作。
- 浏览器登录状态、社区情绪抓取和浏览器专用证据。
- 对评分结果或投资收益作承诺。
